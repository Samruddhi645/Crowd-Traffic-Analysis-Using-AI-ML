# Crowd-Traffic-Analysis-Using-AI-ML

Project Overview

This project focuses on analyzing crowd density and traffic in aerial images captured using a drone. It uses Artificial Intelligence (AI), Machine Learning (ML), and computer vision techniques to detect and count people and vehicles in images and video footage.
The system aims to support crowd monitoring and traffic analysis by identifying areas with high concentrations of people or vehicles.

Objectives

Detect people and vehicles in drone imagery.

Analyze crowd density and traffic conditions.

Display detection results using a Python-based application.

Explore the use of AI/ML for smart monitoring and traffic management.

Technologies Used

Programming Language: Python
AI/ML Model: YOLOv8
Computer Vision: OpenCV
Image Processing: Pillow, NumPy
User Interface: Tkinter
Hardware Platform: Raspberry Pi 5 and camera module

Hardware Requirements

Raspberry Pi 5 (8GB RAM)
Camera module
MicroSD card
Power supply or compatible power bank
Drone with a camera for aerial image/video capture

Software Requirements

Python
Ultralytics YOLO
OpenCV
Pillow
NumPy
Tkinter

Key Features

Image and video input for analysis.

Detection of people and vehicles using a YOLO-based model.

Visual display of detected objects and bounding boxes.

Counting of detected object classes.

Python-based graphical user interface.

Project Workflow

Capture aerial images or video footage using a drone.

Provide the image or video as input to the application.

Process the input using the trained YOLO model.

Detect and count people and vehicles.

Display the detection results for crowd and traffic analysis.

Future Scope

Improve detection performance under different lighting and weather conditions.

Explore real-time crowd and traffic monitoring.

Add density-based alerts for high-crowd or high-traffic areas.

Improve object tracking and traffic analysis capabilities.






























This project was developed as part of our final-year engineering project, focusing on applying AI/ML and computer vision to crowd and traffic monitoring.
